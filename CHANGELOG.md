# Sellery Website Changelog

## 2.0.0 — Luxury Software Edition

### Design system

- Rebuilt the visual direction around a dark technical-luxury software interface.
- Replaced the original marketing-site layout with a more disciplined editorial grid, refined type hierarchy, and tighter spacing system.
- Added a robust light theme that swaps to the supplied light-background Sellery logo.
- Added responsive typography, high-density interface details, and mobile-specific compositions rather than simple desktop stacking.

### Product storytelling

- Introduced the Sellery Control Plane hero interface.
- Added an interactive operating layer with Intelligence, Automation, Commerce, and Capital views.
- Rebuilt the Malach presentation as a flagship software product with its own interface, metrics, activity stream, and supplied identity.
- Added software-style portfolio briefs for Commerce OS, Owned Commerce, Venture Studio, Acquisition Platform, and Signal Layer.
- Reframed consulting, acquisitions, and global operations around Sellery's operator-led model.

### Interaction and motion

- Added persistent theme selection, active navigation, scroll progress, responsive menu behavior, keyboard-accessible tabs, accessible dialogs, visible system feedback, and intent-aware CTAs.
- Added a starfield, ambient light system, global network canvas, data motion, depth effects, and reduced-motion fallbacks.
- Added refined loading, validation, error, and success states to the contact workflow.

### Performance and quality

- Kept the frontend framework-free and dependency-free.
- Added WebP assets, explicit image dimensions, selective lazy loading, preconnects, immutable asset caching, and deferred JavaScript.
- Preserved the dependency-free PDF generator and Resend email workflow.
- Added automated local-link, PDF, recipient, reply-to, validation, and idempotency tests.
- Verified responsive layouts, dark/light themes, mobile navigation, platform controls, portfolio dialogs, contact validation, and the success state in browser smoke tests.
